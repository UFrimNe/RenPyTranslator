# Проверки RPTS 11.26

31 октября 2026, Linux. Основа — полная сборка 11.25.

Прошло 123 теста. Среди новых проверок:

- обычное продолжение переводит найденные готовые ошибки вместе с pending;
- уже исправленный результат повторно не вызывает модель;
- проверка готовых строк работает и при пустой pending-очереди в ядре;
- dry-run/план учитывают автоматические исправления без модели и backup;
- лимит остаётся общим для новых строк и исправлений;
- область UI не захватывает обычный сюжет;
- ошибка модели сохраняет прежний текст, следующий обычный запуск повторяет её;
- отмена до backup не сбрасывает перевод;
- телефонные метаданные определяют настоящего слушателя и автора заметки;
- временные роли предварительной проверки не становятся ролями запроса;
- валидная цитата переживает изменение E-номера и сохраняет кэш профиля;
- выдуманная/удалённая цитата и неверный субъект инвалидируют кэш пола;
- ручной пол не изменяется;
- корректный кэш профиля не вызывает модель, испорченный уточняется;
- отдельное действие repair_gender отсутствует в API и интерфейсе.

Сохранены прежние проверки исходных ролей, сцен/времени, грамматического рода,
разметки, desktop API, телефона/UI, частичной установки и выбора папки.
Провайдеры в тестах сценарные; ответы заранее заданы для проверки поведения
программы, не для оценки литературного качества модели.

Повторно обработана для чтения база из RenPyAuditReport от 30 октября 23:44 UTC
(Bruder, пакеты протокола 11.22). Исходная база не менялась. Подготовка обычного
перевода добавляет 15 готовых строк к 478 pending/error, всего 493.
Род подтверждается у 6 персонажей вместо 0; остальные остаются unknown.
Ни одной строке из отчёта не подставлялся новый русский перевод.

SHA-256 исходной базы:

`0baa5fcaab11dff9b5d3f940e2c42cfe52866fcc09e7d654a9a014e5018cf3a4`

Console self-check, компиляция Python и синтаксис изменённых JavaScript прошли.
При упаковке проверены CRC обоих ZIP, SHA-256 файлов и preflight загрузчика.
runtime и app/desktop совпадают побайтно с 11.25.
Журналы: docs/checks_11_26/.

Ограничения: живые Hy-MT2, Windows/CEF и сама игра здесь не запускались.
Художественное качество и скорость генерации на компьютере пользователя
не измерены. Проверки не заменяют полноценный морфологический/сюжетный анализ
и могут не распознать ошибку при отсутствии достоверных сведений.
