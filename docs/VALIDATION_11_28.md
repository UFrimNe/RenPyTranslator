# Проверки 11.28

Основная исходная проверка: 145 тестов, Linux/Python 3.12, две Windows-проверки
пропущены вне Windows. Проверены новые разрешённые файлы, исходная сборка без
Git/runtime, отсутствие моделей/баз/настроек в поставке и версионные ссылки.
Сохранены проверки SHA-256, архивов, отката, рода, разметки, запуска и UI.

В Windows workflow дополнительно выполняются Chromium UI, компиляция CEF и
native EXE, isolated-Python helper, проверка portable-пакета, тихая установка
в папку с пробелами/кириллицей и удаление с сохранением пользовательских файлов.
Публикация блокируется при провале любого обязательного шага. Эти проверки не
подтверждают художественное качество живой модели и не заменяют проверку
полного закрытия и повторного открытия окна CEF на пользовательском ПК.
