## RenPyTranslator 11.28

Полная Windows-версия с запуском через EXE, установщиком и сборкой из исходников.

### Что скачать

| Файл | Назначение |
| --- | --- |
| **RenPyTranslator_11.28_Setup_win64.exe** | Рекомендуемый вариант: установить программу и создать ярлыки |
| **RenPyTranslator_11_28_win64.zip** | Полная portable-версия: распаковать и открыть RPTS.exe |
| **RenPyTranslator_11_28_source.zip** | Исходники и Build.bat для самостоятельной сборки |
| SHA256SUMS.txt | Контрольные суммы |
| update.json | Используется автоматическим обновлением |

### Изменения

- Корневой RPTS.exe запускает CEF без консоли; системный Python/.NET пользователю не нужен.
- Полный установщик EXE: установка в профиль пользователя, ярлыки, обычное удаление Windows.
- Сохранены RPTS.bat, RPTS.vbs, RPTS-Console.bat и RPTS-Debug.bat.
- Весь код сборки включён в исходники; Build.bat собирает EXE, portable ZIP и Setup EXE.
- Публичный main и понятная главная страница с быстрыми ссылками.
- Обновления используют обычные версионные релизы; технические dev-теги больше не создаются.
- Перевод, промпты, профили и формат проектов не менялись.

### Переход с 11.27

Закрой программу и один раз распакуй новый portable ZIP в прежнюю папку с заменой файлов.
Папки data и runtime/local_ai не удаляй. Старые dev-теги удалены, поэтому загрузчик
11.27 со старой ссылкой не сможет найти этот релиз. Следующие обновления доступны из нового лаунчера.

Setup по умолчанию ставит новую копию в профиль пользователя. Если нужно сохранить
существующую библиотеку на месте, укажи её прежнюю папку или используй portable ZIP.
Модели и игры в поставку не входят; при первом переводе загружаются отдельно.
