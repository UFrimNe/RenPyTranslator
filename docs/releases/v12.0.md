## RenPyTranslator 12.0 — локальный ИИ и быстрый Google

RPTS — бесплатная программа. Нет подписки и оплаты функций; локальный ИИ и Google без ключа не требуют API-ключа. Платные внешние API остаются отдельным необязательным способом.

- В карточке игры → Обзор появился выбор «Локальный ИИ / Google — быстрый». Одна обычная кнопка запускает выбранный способ. Выбор сохраняется отдельно для каждой игры.
- Google работает без скачивания модели и использует общий анализ, базу, перевод телефона/UI, сборку и установку патча. Текст отправляется Google через интернет; художественная редактура и проверка рода локальным ИИ в этом режиме не выполняются.
- Сохранены пакетные запросы, таймаут 30 секунд, два повтора с увеличением задержки и пауза между запросами. При обычном сбое основного веб-подключения используется запасное. При 429/CAPTCHA — сохранение прогресса и понятное сообщение о продолжении позже, без обхода ограничения.
- Повреждённые разделители пакета вызывают деление пакета, а не объединение реплик. ID, говорящие, защищённые токены и ручные правки сохраняются.
- Источник готовых строк определяется по базе, а не выбранной модели. В библиотеке видны Google, локальный ИИ, ручные правки и смешанные версии.
- Запросы/ответы Google, ошибки, переключения и повторы входят в диагностический ZIP.
- Обновлена справка. Сохранены CEF, стандартный выбор папки Windows, консоль/BAT/VBS, автообновление, резервные копии и откат.

Полный установщик EXE, полный portable ZIP, исходники, контрольные суммы и отчёт о размере прилагаются. Python, .NET и CEF включены. Модели загружаются отдельно только для локального ИИ.

Google используется через неофициальный веб-интерфейс без ключа: доступность и скорость зависят от сервиса. Отчёты VirusTotal для прежних версий не относятся к новым файлам.
