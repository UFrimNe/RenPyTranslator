# RPTS 11.26 · автоматическая проверка рода и профилей

Перевод Ren’Py-игр на русский с локальным ИИ. Windows 10/11 x64.

## Быстрый запуск

1. Полностью распакуй архив в доступную для записи папку. Запусти **RPTS.bat**. Команды вводить не нужно — откроется графическое окно CEF.
2. **Библиотека → Добавить игру**. Укажи папку игры или её EXE.
3. Открой карточку → **Начать перевод → Начать перевод**. Первый запуск подготовит игру, модель и движок. Автоматическую установку можно оставить включённой.

Сменить модель и посмотреть параметры: **Модели и перевод**. После загрузки модели и llama.cpp перевод работает локально без API-ключа. В 11.23 кнопка «Играть» предлагает установить текущий перевод и запустить игру либо просто запустить её. Устанавливается готовая часть из рабочей базы с последними правками; новая версия сохраняется в библиотеке. В 11.24 добавлены исходные опорные цитаты об отношениях и времени для конкретного момента сцены; усилены правила естественной речи и сохранения шуток.

Кнопка папки открывает стандартный современный диалог Windows — и для игры, и для импорта готового патча. Можно вставить путь вручную, в том числе путь к EXE. Отмена диалога сохраняет уже введённый путь. Системный выбор выполняется отдельным процессом .NET и не требует нового CEF-контейнера. При его ошибке можно продолжать работу с ручным вводом пути.

Параметры перевода общие для следующих запусков всех игр. Изменения применяются только после «Сохранить настройки»; несохранённые правки сохраняются в памяти при переходах между страницами до закрытия окна. Готовый текст при смене модели не сбрасывается автоматически.

## Обновить до 11.26

Закрой RPTS, консоль и игру. Распакуй содержимое папки `RenPyTranslator` из **RPTS_Update_11_26.zip** поверх папки программы с заменой файлов. Архив обновления предназначен для CEF-сборок 11.19–11.25 с комплектными Python/.NET/CEF. Не удаляй `data`, `projects` и `runtime/local_ai`: там находятся рабочие данные и модели. Если комплектные среды отсутствуют или повреждены, используй полную сборку.

После запуска: **Библиотека → игра → Обзор → Продолжить перевод**. Профили и найденные ошибки рода в машинных строках проверяются автоматически. Для этого не нужны полный сброс и ручное пересоздание профилей.

Чтобы проверить текущий результат: **Обзор → Играть → Установить перевод и запустить**. Работает и после остановки частичного перевода. «Просто запустить игру» оставляет уже установленный патч как есть. Отдельная установка старых версий остаётся во вкладке «Версии перевода».

В обновлении сохранены исправления запуска 11.21.1, рабочий CEF-контейнер, иконки и стандартный выбор папки Windows. Если окно не открывается, запусти **RPTS-Debug.bat** и отправь `data/reports/RenPyStartupReport.zip`.

Старые папки переносятся по правилам 11.19 с журналом и сохранением конфликтующих копий. Не объединяй базы вручную с перезаписью. Предупреждения о конфликтах видны в «Настройки лаунчера → Папки и данные».

**GitHub и автоматическое обновление пока не реализованы в выпуске.** В настройках оставлена информационная вкладка «Обновления · позже». Нет фоновой проверки, скачивания или установки обновлений приложения. Код экспериментального установщика в сборку не включён. Загрузка моделей по явной команде пользователя сохранена.

## Род проверяется автоматически

Нажми обычное **Начать перевод / Продолжить перевод**. Сохранённые ИИ-профили сверяются с исходными доказательствами; неподтверждённые выводы не используются как установленный род. Проверенные профили сохраняют кэш, неподтверждённые при необходимости уточняются автоматически.

Готовые автоматические строки проверяются до перевода. Подтверждённые ошибки рода добавляются к текущей очереди; перед их изменением автоматически создаётся резервная копия базы. Ручные и подтверждённые правки не выбираются. Ошибочный ответ модели не стирает прежний текст: его можно повторить тем же «Продолжить перевод».

Отдельной кнопки исправления рода и дополнительного YES нет. Полный сброс и пересоздание всех профилей не требуются. Неизвестный пол не определяется по одному имени или мягкой манере речи. Для установки текущего результата остаётся **Играть → Установить перевод и запустить**.

## Работа с текстом и интерфейсом

После обновления до 11.24 один раз выполни **Игра → Инструменты → Повторить анализ**. Анализ запишет границы веток из скриптов/скомпилированного AST и сохранит готовые переводы при неизменном исходнике. Затем можно продолжить перевод. Для старой базы без этих сведений используется ограниченный поиск контекста.

Готовые строки с обнаруженными ошибками рода повторяются автоматически. Чтобы полностью обновить художественный стиль остальных строк, сначала сохрани текущую версию во вкладке «Версии перевода», затем выбери **Инструменты → Перевести заново**. Эта команда сбрасывает готовый текст, в том числе ручные правки, после подтверждения и создания резервной копии базы. Для проверки перед полным перепереводом есть **Инструменты → Проверка качества**: добавлены сцены про незнакомцев, друзей, сближение, шутку с повтором и речь в воспоминании.

Опорные цитаты ограничены по объёму и не требуют отдельного прохода модели. Они выбираются из текущего непрерывного блока. Будущая близость не должна переноситься на раннее знакомство. Явные повествовательные переходы разделяют блоки, а реплика «увидимся завтра» остаётся планом. Между произвольными label хронология не угадывается.

Проценты показывают покрытие строк, а не гарантированное художественное качество. Остановка завершается после текущего запроса; уже записанные строки остаются в базе.

Ручные правки сохраняются как подтверждённые. Чтобы увидеть их в игре, нажми **Играть → Установить перевод и запустить**. После «Остановить» дождись завершения текущей задачи: готовые строки сохранятся, затем станет доступен запуск.

Телефон и UI входят в обычный перевод: доступные сообщения и надписи извлекаются из скриптов и архивов при анализе игры. Для Emberbound сохраняются порядок, говорящие и контекст телефонных сообщений. Вкладка «Телефон и интерфейс» показывает количество найденных и готовых строк; кнопка «Перевести телефон и UI» обрабатывает эту часть отдельно. При отсутствии строк сначала повтори анализ файлов.

«Текст всё ещё не найден?» раскрывает запасной путь: включить запись отображаемых строк → открыть нужные экраны игры и закрыть игру → импортировать текст → перевести. Это журнал через Ren’Py, а не сканирование памяти процесса. Захват не включается автоматически. Произвольный текст на изображениях не распознаётся автоматически.

Модель, вычисления, режим перевода, фильтр строк и игра для отчёта выбираются в оформленных списках внутри лаунчера. Поддерживаются стрелки, Home/End, поиск вводом начала названия, Enter, Escape и Tab. Выбор папки игры остаётся стандартным диалогом Windows.

## Запуск и диагностика

Python, .NET и CEF входят в полную сборку. Если требуется Visual C++ Runtime, заверши официальный установщик Microsoft из `runtime/installers/VC_redist.x64.exe`.

**RPTS.vbs** открывает то же окно без консольной вспышки, если Windows Script Host включён. **RPTS-Console.bat** сохраняет всё прежнее консольное меню. Одновременные изменяющие операции из двух окон блокируются.

При проблеме: **Помощь и диагностика → Диагностика → выбрать игру → Собрать отчёт → Открыть ZIP**. Отчёт может содержать исходный текст и переводы; API-ключи скрываются. Если окно не открывается, используй консоль; журналы находятся в `data/logs`.

Проверки и ограничения сборки: `docs/VALIDATION_11_26.md`.

## Если графическое окно не открывается

1. Закрой все окна RPTS. Распакуй содержимое папки RenPyTranslator из RPTS_Fix_11_21_1.zip поверх программы с заменой файлов. Проекты, модели и переводы не удаляй.
2. Запусти RPTS.bat. Возвращён тот же CEF-контейнер, который использовался в 11.20; новый интерфейс и иконки сохранены.
3. Если окно не появилось, запусти **RPTS-Debug.bat**. Он сохраняет код завершения, вывод нативного процесса и диагностику загрузчика .NET. После завершения окно консоли останется открытым. Отчёт: **data/reports/RenPyStartupReport.zip**.

При ошибке обычного запуска этот ZIP тоже создаётся автоматически, если Python смог запустить загрузчик. Журналы — data/logs/launcher.log и desktop-process.log. Старое консольное меню остаётся отдельным резервным интерфейсом.

Точная первопричина падения 11.21 на конкретном Windows-компьютере без его журнала не установлена. Исправление возвращает рабочую версию контейнера и устраняет подтверждённый пропуск сообщения о ненулевом коде завершения. Ошибки системного выбора папки изолированы от основного GUI.
