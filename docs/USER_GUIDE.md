# RPTS 12.0 — бесплатный переводчик Ren’Py

Windows 10/11 x64. Графическое окно CEF, локальный ИИ и Google без ключа. Программа бесплатная, подписка на RPTS не нужна.

## Начать перевод

1. Установи полную программу через Setup EXE или распакуй полный ZIP и открой **RPTS.exe**. Python, .NET и CEF уже в комплекте. BAT/VBS остаются альтернативой.
2. **Библиотека → Добавить игру**. Выбери папку игры через стандартное окно Windows или вставь путь к её EXE. Файлы игры переносить не нужно.
3. Открой карточку. В **Обзор → Способ перевода** выбери **Локальный ИИ** или **Google — быстрый**. Нажми **Начать перевод**.

| Способ | Что нужно знать |
| --- | --- |
| Локальный ИИ | При первом запуске загрузятся модель и llama.cpp. Затем интернет для перевода не нужен. Учитываются контекст и персонажи; проверки рода выполняются автоматически. |
| Google — быстрый | Модель и видеокарта не нужны. API-ключ не нужен. Текст отправляется Google через интернет. Возможны буквальный перевод, ошибки рода и ограничения сервиса. |

Способ сохраняется отдельно для каждой игры. Телефон/UI используют этот же способ. Готовые строки и ручные правки не сбрасываются при переключении. Локальный ИИ продолжает автоматически проверять обнаруженные ошибки машинных строк; принудительный повторный перевод готового текста находится в инструментах и требует подтверждения с резервной копией.

Для изменения локальной модели: **Модели и перевод → Каталог моделей**. CPU/CUDA/Vulkan, режим текста, указания и глоссарий: **Параметры перевода**. Эти параметры относятся к ИИ и общие для игр; Google не получает ИИ-промпты, профили и редактуру.

## Google: таймауты и продолжение

Перевод идёт пакетами до 64 строк / 2200 исходных символов с паузой между запросами. При повреждении разделителей пакет делится на меньшие части, чтобы не смешивать реплики. Таймаут одного запроса — 30 секунд; обычные ошибки повторяются до двух раз с увеличением задержки. При сбое основного веб-подключения используется запасное.

При 429/CAPTCHA RPTS прекращает запросы и сохраняет уже готовые строки. Дождись завершения задачи, затем продолжи позже кнопкой **Продолжить перевод**. Это не обход лимитов. Веб-интерфейс Google неофициальный, поэтому доступность и время перевода не гарантируются. Платный Google Cloud остаётся отдельным необязательным вариантом в консоли.

## Играть с готовой частью

Нажми **Остановить**, дождись сохранения, затем **Играть → Установить перевод и запустить**. Готовая часть соберётся из рабочей базы с последними правками и сохранится в библиотеке. Непереведённый текст останется исходным. Затем можно продолжить перевод.

**Просто запустить игру** запускает её с уже установленным патчем. Старые сохранённые версии доступны на вкладке **Версии перевода**. Источник строк указан в библиотеке: Google, модель ИИ, ручные правки или смешанный перевод.

## Где что находится

| Задача | Путь |
| --- | --- |
| Способ перевода, запуск и продолжение | Игра → Обзор |
| Исходник, поиск, ошибки, ручные правки | Игра → Текст и ошибки |
| Сохранение, установка и импорт патча | Игра → Версии перевода |
| Все сохранённые переводы | Библиотека → Готовые переводы |
| Телефон и интерактивные панели | Игра → Телефон и интерфейс |
| Профили, повторный анализ, повторный ИИ-перевод, восстановление | Игра → Инструменты |
| Модель и настройки ИИ | Модели и перевод |
| Прогресс, журнал, история | Задачи |
| Папки и консольное меню | Настройки лаунчера |

| Отчёт о проблеме одним ZIP | Помощь и диагностика → Диагностика |

**Ctrl+K** открывает поиск действий. Списки поддерживают стрелки, Home/End, ввод начала названия, Enter, Escape и Tab. Выбор папки игры — стандартный Windows.

## Телефон и интерфейс

Доступный текст читается из скриптов и архивов при обычном анализе. Запускать игру для этого не нужно. Для пропущенного текста повтори анализ, затем нажми **Перевести телефон и UI**. Готовые переводы сохраняются.

Раскрываемый дополнительный захват — запасной способ для текста, который формируется во время игры. RPTS записывает показанные Ren’Py строки в журнал; это не чтение памяти процесса. После посещения нужного экрана закрой игру, импортируй строки и переведи найденное. Текст на изображениях автоматически не распознаётся.

## Файлы и обновления

| Папка | Содержимое |
| --- | --- |
| `app`, `runtime/python`, `runtime/dotnet` | Программа и комплектные среды |
| `runtime/local_ai` | Скачанные модели и llama.cpp |
| `data/projects` | Базы, профили, патчи и резервные копии игр |
| `data/translations` | Сохранённые версии переводов |
| `data/settings` | Настройки |
| `data/reports` | Диагностические ZIP |
| `data/jobs`, `data/diagnostics`, `data/logs` | История, запросы, ответы и ошибки |

Игры остаются в своих папках. Обновление из GitHub Releases проверяется при запуске; установка доступна в настройках. Заверши задачу и сохрани ручные правки перед перезапуском. Модели, игры, настройки и переводы сохраняются. Без интернета локальный перевод продолжает работать.

Для старой 11.27, использующей удалённый технический тег: закрой RPTS и один раз распакуй новый полный ZIP поверх программы с заменой, сохранив `data` и `runtime/local_ai`. Отдельные архивы обновлений не нужны. В portable-версии оставляй RPTS.exe рядом с app и runtime.

## Ошибки и диагностика

**Помощь и диагностика → Диагностика → выбрать игру → Собрать отчёт**. В одном ZIP: база, настройки, журналы, запросы/ответы ИИ и Google, причины переключений и повторов. Отчёт может содержать исходный текст игры; API-ключи скрываются.

Если окно не открывается, запусти **RPTS-Debug.bat** и приложи `data/reports/RenPyStartupReport.zip`. **RPTS-Console.bat** открывает прежнее меню. Одновременные изменяющие операции блокируются.

Качество зависит от модели и исходника; 100% строк означает покрытие, а не гарантию художественного качества. Платные внешние API оплачиваются только по условиям выбранного провайдера; для обычного локального перевода и Google без ключа они не нужны.
