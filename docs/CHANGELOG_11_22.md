# RPTS 11.22 — эмоции, манера речи и исправления перевода

Обновление от 28 октября 2026. Основа — полная сборка 11.21.1; интерфейс,
иконки, CEF-контейнер, стандартный выбор папки и восстановление запуска сохранены.

## Что показал отчёт Emberbound

В присланном отчёте указана версия приложения 11.19 и Hy-MT2 7B Q6_K / CUDA.
Инструкции перевода в ней совпадают с основой 11.21.1. Зафиксировано 603 готовых
строки, 5 ошибок, 2866 ожидающих строк и 27 строк, требующих захвата во время игры.
Последний запуск остановлен пользователем, а не завершён переводом всей игры.

Пять ошибок: три потери/добавления тегов оформления при попытках исправить UI;
два повторяющихся смешения алфавитов в слове `STУДИЯ`. Дополнительно обнаружена
ложная проверка мужского рода в фразе «Я к тебе пришёл — мама сказала…».

Модель получала цельную строку и контекст 4 предыдущих / 3 следующих строк.
Но наличие контекста само по себе не обеспечило понимание: дружеское отмахивание
превратилось в «Убирайся, хватит быть таким сентиментальным», а телефонное обращение
«пишу тебе» — в физическое «пришёл к тебе». Есть и грамматическое «этот место».

## Перевод

- Инструкции различают намерение и силу эмоции: подкол, заботу, смущение,
  раздражение, спокойную речь. Слова, частицы и ритм должны передавать эту разницу;
  не добавляются чувства, ремарки, шутки и сленг ради «оживления».
- Для реплики с недостатком собственной речи персонажа в ближайшем контексте
  добавляются до двух его прежних исходных реплик из той же сцены. Это примеры
  манеры, не новые события и не дополнительные строки для перевода. Чужие персонажи,
  другие ветки и неустановленные говорящие каталога исключены. При малом контекстном
  окне объём уменьшается; при 2048 токенах примеры отключаются.
- Конкретные китайские выражения получают условные смысловые подсказки: приторные
  нежности, дружеское отмахивание, задумчивость, скука, метафора ожидания/ремонта.
  Это не готовые переводы и не жёсткая классификация эмоций по одному слову.
- Для телефонных сообщений уточнено различие между перепиской и физическим визитом,
  для коротких ответов — между обращением по имени и самоидентификацией, между
  советом собеседнику и намерением говорящего.
- Мат допустим, если передаёт смысл и силу исходника. Он не добавляется ко всем
  дружеским подколам. Английский перевод остаётся вспомогательным, оригинал важнее.
- Форматы моделей сохранены: Hy-MT2 получает одну цельную строку с отдельным
  контекстом, остальные используют свои прежние контракты ответа. Промпт обновлён
  для всех девяти моделей каталога. Дополнительного прохода по каждой реплике нет;
  параметры sampling и модели не менялись.

## Исправления и диагностика

- Проверка рода не приписывает слова мамы герою после тире; аналогично исправлена
  проверка собеседника. Женские формы первого лица у известного мужчины по-прежнему
  проверяются. Сомнительные конструкции не переписываются заменой всех окончаний.
- Исправляется только известное смешанное написание слова «студия» и его форм.
  Бренды в оригинале, URL, переменные и другие смешанные слова не транслитерируются.
- Строка с тегами сначала исправляется целиком. Для локального llama.cpp в режиме
  single_text попытка исправления получает грамматику точного порядка маркеров.
  Это ограничение структуры ответа, не гарантия правильного смысла или выделения.
  Удалённым API эта расширенная настройка не отправляется.
- Резервный перевод фрагментов UI больше не показывает сырые теги в контексте;
  программа восстанавливает их из оригинала. Неправильное оформление не принимается
  через молчаливое удаление тегов.
- Добавлена проверка наблюдавшегося несогласованного «этот место».
- Диагностика связывает исходные запросы, ответы, исправления и финальный результат
  по ID строки. Сохраняются ID примеров манеры, локальные исправления и версия
  промпта 11.22. Всё попадает в обычный RenPyAuditReport.zip.
- Кэш старого промпта для новых запросов отделён. Готовые строки не сбрасываются
  из-за изменения стиля; ручные правки и сохранённые версии сохраняются.

## Как применить

Закрой программу и игру. Наложи содержимое `RenPyTranslator` из обновления на папку
программы с заменой файлов. Сборки CEF 11.19–11.21.1 поддерживаются при сохранных
комплектных средах Python/.NET/CEF. Данные, модели и игры удалять не нужно.

Продолжение перевода обработает pending/error. Для применения новой манеры к уже
готовым диалогам сначала сохрани текущую версию, затем выбери в карточке игры
«Инструменты → Перевести заново». Действие делает резервную копию и просит
подтверждение. По окончании сохрани новую версию перевода и установи именно её.

## Границы проверки

Литературное качество нового промпта на живой Hy-MT2 в этой среде не измерялось.
Автотесты проверяют передачу контекста, роли, оформление, исправления и сохранность
прогресса; они не доказывают, что каждая реплика станет художественно удачной.
Для предметного сравнения добавлены десять сцен из отчёта с исходником, прежним
ответом и критериями: `app/templates/emberbound_voice_cases.json`. Оценщик
`app/tools/evaluate_russian.py` сохраняет отдельные оценки смысла, естественности,
голоса и эмоции; они заполняются человеком, а не выдаются автоматически за качество.

Технические источники для формата запросов (проверены 28.10.2026):

- https://huggingface.co/tencent/Hy-MT2-7B — стиль, контекст, параметры генерации.
- https://github.com/ggml-org/llama.cpp/blob/master/grammars/README.md — GBNF.
