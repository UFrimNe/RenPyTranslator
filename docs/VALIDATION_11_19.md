# Проверка RPTS 11.19 — 27 октября 2026

## Выполнено

- 30 автоматизированных офлайн-проверок в `app/tests/test_desktop.py`: миграция и сохранение конфликтующих папок; восстановление общего work; старые проекты только с аудитом; блокировка конкурентных операций; карточки и счётчики; сохранение патча в библиотеке; установка и удаление на временной игре без изменения исходника; отклонение повреждённого и чужого патча; защита путей; редактирование с маркерами и конфликтом версий; резервная копия до ручной правки; отмена и восстановление прерванной задачи; неподготовленная модель; авторизация API; полноценные фоновые операции аудита, сборки и диагностического ZIP.
- Проверены конфигурации всех девяти моделей. Для Hy-MT2 проверены одиночный целевой фрагмент, передача соседей как контекста, пола говорящего и исключение отклонённого черновика из повторного перевода. Проверена отмена после одного запроса: уже записанная строка сохранена, следующая остаётся pending.
- Браузерный сценарий с реальным локальным Python API: две тестовые игры, поиск, ручная правка, библиотека, девять карточек моделей, диагностика, сохранение настроек, параметры запуска, ошибка неверного пути и выбор папки. Ошибок JavaScript не обнаружено. Макет просмотрен при 1360×900 и 1024×768; горизонтального переполнения нет. Использован Chromium headless 140, а не Windows CEF.
- Консольная самопроверка и компиляция Python-файлов.
- C#-оболочка скомпилирована компилятором .NET SDK 8.0.427 против .NET 8 и CefSharp 154.0.340. Создан Windows GUI x64 apphost официальным Microsoft.NET.HostModel. Предупреждения CS1701 относятся к ссылкам CefSharp на сборки .NET 6 при использовании .NET 8. Ошибок компиляции нет.
- Файлы CEF скопированы с проверкой SHA-256 по исходным NuGet-файлам. 507 файлов .NET/Python сверены по CRC с официальными архивами; исправлены обнаруженные неполные локальные копии. Перед выдачей проверяется целостность итогового ZIP.

## Границы проверки

Среда проверки — Linux/Python 3.12.14. Исполнение Windows CEF, установленного Python 3.14.10, Visual C++ установщика, CUDA/Vulkan и самой Emberbound в этой среде не выполнялось. Полный новый перевод реальной игры и оценка художественного качества на GPU также не выполнялись. Это первая сборка графической оболочки для проверки на Windows.

Материалы прошлой проверки 11.18 лежат отдельно в `docs/archive`; они не считаются повторно выполненными тестами этой сборки. Новая оболочка использует прежние переводчик, адаптер телефона, защиту привязки строк и модельные промпты. Защита структуры и успешные тесты не доказывают естественность каждой реплики.

## Повторить

`runtime/python/python.exe app/tests/test_desktop.py`

Самопроверка CLI: `runtime/python/python.exe app/tools/rpts_menu.py --self-check`.

Для браузерного теста `app/tests/test_frontend.py` нужен отдельный Python с Playwright и установленный Chromium. Необязательная переменная `RPTS_TEST_BROWSER` задаёт полный путь к тестовому браузеру. Все игровые данные создаются в временной папке.

При проблеме на Windows: «Диагностика → Собрать отчёт». Если окно не запускается, используй RPTS-Console.bat и приложи ZIP; журналы CEF и оболочки также находятся в data/logs.
