# Версионные обновления

Лаунчер проверяет https://github.com/UFrimNe/RenPyTranslator/releases/latest/download/update.json.
Манифест указывает на полный ZIP в конкретном релизе v<версия>, содержит SHA-256,
размер, commit SHA и номер сборки. Канал — stable. Проверка проходит в фоне при
запуске; без интернета локальный перевод продолжает работать.

Публикация выполняется из main через .github/workflows/release.yml. Dev проходит
проверки и собирается в Actions artifact без создания release-тегов. Для следующего
публичного выпуска нужно увеличить версию и добавить docs/releases/v<версия>.md.
Уже опубликованный релиз не перезаписывается. Повреждённая/неполная сборка или
сбой установки в CI не публикуются. Все ассеты сначала загружаются в draft,
проверяются по размеру/хешу и только затем релиз становится latest.

Загрузчик принимает только HTTPS и фиксированный репозиторий, совпадающую
версию тега/архива, размер и SHA-256. Установщик проверяет внутренний состав
и хеш каждого файла; запрещены traversal, ADS, Windows reserved names, дубликаты
регистра, symlink/junction и пользовательские файлы. Доверие к издателю основано
на GitHub/HTTPS; отдельной криптографической подписи приложения пока нет.

Установка недоступна во время перевода и других задач. Независимая копия Python
ждёт backend, CEF и bootstrap через process handles, захватывает блокировки,
сохраняет резервную копию и журнал намерения перед каждой заменой. Ошибка
замены запускает откат. Последняя копия — data/updates/rollback. Модели
в runtime/local_ai, data и внешние игры не принадлежат обновлению.

Setup EXE ставит ту же программу, что portable ZIP, в профиль пользователя.
Работающее приложение отмечено Local\RPTS-Running; установщик просит закрыть
его перед заменой файлов. Удаление сохраняет созданные пользователем data и модели.

Журнал updater.log, результат, манифест и журнал отката входят в диагностический ZIP.
При повреждении самой среды Python после аварийного выключения можно распаковать
полный ZIP заново, сохранив data и runtime/local_ai.

Переход с 11.27 выполняется один раз вручную полным ZIP: в ней зафиксирована
ссылка на удалённый dev-latest. Новый загрузчик больше не зависит от этих тегов.
