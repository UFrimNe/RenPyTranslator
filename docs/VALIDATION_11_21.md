# Проверка 11.21

Выполнены 32 проверки backend на временных проектах. Сохранены проверки извлечения, базы, патчей, резервирования, авторизации и диагностики; добавлена проверка локальной выдачи новых JS-модулей.

Браузерный сценарий проверяет существующие страницы и новый протокол выбора папки: запрос для игры и импорта, успешный результат, отмену, ошибку и путь с кириллицей, пробелами и кавычками. Проверено отсутствие старого HTML-проводника и запросов к API перечисления папок. Отдельно проверен ручной ввод при отсутствии CEF-моста. Ответы нативного диалога в этих тестах эмулируются, это не является запуском Windows-диалога.

Все SVG интерфейса используют одно семейство Uicons Regular Rounded. Макет просмотрен в Chromium; сохранены проверки 1360×900, 1024×768, 920×680 без горизонтального переполнения и ошибок JavaScript. При запуске интерфейса нет обращений к CDN или сторонним серверам. Переход на сайт Flaticon выполняется только по нажатию ссылки авторства.

Новый C#-контейнер скомпилирован компилятором .NET SDK 8.0.427 против .NET 8 и CefSharp 154.0.340. Используется Windows FolderBrowserDialog с AutoUpgradeEnabled=true, UseDescriptionForTitle=true и владельцем RPTS. Существующий apphost и все CEF/Python/.NET runtime-файлы сохранены. Предупреждения CS1701 о ссылках CefSharp на .NET 6 при .NET 8 сохранены, ошибок компиляции нет.

Среда проверки — Linux/Python 3.12/Chromium headless. Открытие реального диалога Windows и запуск обновлённого нативного контейнера на Windows здесь не выполнялись. Первый запуск нового выбора папки нужно проверить на Windows. Перевод игры и GPU в этой итерации не запускались; переводческий код сверяется по SHA-256 с 11.20.

Backend: runtime/python/python.exe app/tests/test_desktop.py. UI: app/tests/test_frontend.py с отдельным Playwright/Chromium и RPTS_TEST_BROWSER. Тест аудита открытого исходника не скачивает необязательный декомпилятор; проверки выполнялись с блокировкой внешних соединений в Python и сетевых дочерних команд.
