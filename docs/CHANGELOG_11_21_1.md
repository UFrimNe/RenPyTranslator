# Восстановление 11.21.1

- CEF-контейнер (EXE, DLL, deps/runtimeconfig) возвращён побайтно из работавшей 11.20. Иконки Flaticon и интерфейс 11.21 сохранены.
- Системный Windows FolderBrowserDialog вынесен в отдельный .NET-процесс без ссылок на CefSharp. Его сбой возвращает ошибку в поле выбора и не должен завершать GUI.
- Загрузчик теперь сохраняет stdout/stderr нативного процесса и код завершения, включая ошибки до C# Main. Ненулевой код больше не скрывается.
- Проверка целостности небольших критических файлов обнаруживает неполное распаковывание и повреждение. Pythonw при отсутствии заменяется запуском Python.exe. BAT не закрывается молча после ошибки.
- Добавлены RPTS-Debug.bat и отдельный RenPyStartupReport.zip; обычный неудачный запуск также пытается собрать отчёт.
- Переводчик, промпты, сохранённые проекты и модели не изменяются. Автообновления и установщик не добавлялись.

Без Windows-журнала пользователя нельзя доказать, какая именно ошибка нативного процесса вызвала исходный сбой. Тестом подтверждено отдельное исправление: прежний загрузчик просто возвращал ненулевой код без журнала и сообщения.
