# Изменения 11.19

- Настоящее CEF-окно на CefSharp с локальным HTML/CSS/JS-интерфейсом; WinForms служит только контейнером окна. Браузерный компонент не заменён WebView2 или встроенными диалогами Windows.
- Каталог игр, карточки моделей, отдельная библиотека версий переводов, прогресс и журналы операций, редактор строк с сохранением маркеров и защитой от устаревшей правки.
- Фоновые операции через существующие Python-функции. Остановка между запросами; сохранение готовых строк. Диагностика в одном ZIP.
- Перенос прежних рабочих папок в data и runtime с журналом, резервными конфигурациями и сохранением конфликтующих копий.
- Проверка целостности импортируемого патча и соответствия игре перед добавлением в библиотеку. Снимки переводов не зависят от дальнейших изменений рабочего патча.
- Проверка одной активной операции между GUI и CLI, авторизация локального API, запрет внешней навигации CEF.
- В архив включены среды запуска; CLI и расширенные функции сохранены.
- Исправлены сообщение о числе проходов Hy-MT2, ошибка события добавления собранного патча, блокировка открытия папок и частичное сохранение неверных настроек.

Политика художественного перевода 11.18 сохранена. Новая оболочка не является новым промптом и сама по себе не доказывает улучшение качества модели. Hy-MT2 по умолчанию получает один целевой фрагмент с соседними репликами как контекстом; свободная редактура остаётся экспериментальной настройкой. Мат допускается по смыслу и силе исходника.
