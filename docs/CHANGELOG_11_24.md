# RPTS 11.24 — отношения и время в контексте сцены

В отчёте 11.22 использовалась Hy-MT2 7B Q6: одна строка на запрос,
четыре предыдущие и три следующие реплики. Фраза о дружбе детства выпадала
из окна контекста. Шутка «напоминаю тебе, чтобы ты напомнил мне» превращалась
в обычную просьбу — практический смысл сохранялся, но характер речи терялся.

## Изменения

- Добавлено situation_context: до четырёх ранних цитат исходника о
  знакомстве, дружбе, дистанции, времени или интонации. Это свидетельства
  для текущей сцены, а не постоянный статус отношений. Вопросы, отрицания
  и воспоминания сохраняются в исходной формулировке.
- Промпты требуют учитывать отношения в момент реплики. Тепло не доказывает
  роман, подкол — вражду; позднее признание не делает раннее знакомство
  интимным. Обращения и переходы ты/вы требуют основания в исходнике.
- Разные ветки сценария и явные повествовательные переходы времени разделяют
  соседний контекст, примеры голоса и пакеты. Реплика «увидимся завтра»
  остаётся планом, не перемещает сцену на следующий день.
- Цитируемая речь внутри повествования помечается отдельно: у неё свой
  голос и время. «Вчера/завтра» относятся к моменту речи, не к дате компьютера.
  Для телефона передаётся буквально записанное время, если оно доступно.
- Усилены инструкции по естественному русскому синтаксису, сохранению
  подтекста, недосказанности, устройства шуток и намеренных повторов.
  Мат допустим по исходному тону, но не добавляется для украшения.
- Адресные подсказки: 五花肉 — свиная грудинка, не отбивная; 狼吞虎咽 —
  манера есть, не вид персонажа; дружеское «猛兽» не следует без основания
  превращать в «тварь»; 哥 у приятеля не создаёт буквального брата.
  Это подсказки, а не готовые подстановки перевода.
- В диагностике сохраняются границы контекста и ID опорных цитат.
  Проверочный набор расширен с 37 до 43 сцен про незнакомцев, друзей,
  сближение, шутку с повтором, детское воспоминание и время планов.

Формат ответа каждой модели сохранён. Hy-MT2 возвращает одну целевую строку
обычным текстом; модели с JSON сохраняют свои контракты. Контекст доходит
до исправлений и разделённых пакетов. Соседи остаются справочными:
объединять их с целевой строкой нельзя.

## Объём и ограничения

Дополнительного прохода ИИ для анализа отношений нет. Поиск цитат ограничен
текущим непрерывным блоком: до 96 предыдущих строк с метаданными веток,
до 24 в старой базе без них. Максимум дополнительных исходных цитат:
640 символов при контексте свыше 4096 токенов, 240 при 2049–4096,
0 при 2048 и меньше. Общие инструкции и служебные поля тоже занимают токены;
отсутствие нового вызова не означает нулевую прибавку времени.

Это ограниченный контекст сцены, а не полная модель всех маршрутов игры.
Хронология между произвольными label не угадывается по номеру или порядку
файлов. Неявные переходы могут потребовать уточнения по отчёту.
Готовый художественный результат зависит от модели и требует оценки.

## Применение

1. Закрой RPTS и игру. Распакуй папку RenPyTranslator из RPTS_Update_11_24.zip
   поверх CEF-сборки 11.19–11.23 с заменой файлов. Данные и модели не удаляй.
2. В карточке игры выбери **Инструменты → Повторить анализ**. Это добавит
   сведения о ветках с сохранением готовых переводов при неизменном
   исходнике. Новые метаданные не меняют ID и хеш исходной строки.
3. Для новых строк нажми **Продолжить перевод**. Для сравнения модели
   сначала можно запустить **Инструменты → Проверка качества**.
4. Готовые строки сами не переписываются. Чтобы обновить их стиль,
   сохрани версию во вкладке **Версии перевода**, затем выбери
   **Инструменты → Перевести заново**. Эта команда сбрасывает и ручные
   правки; предусмотрены подтверждение и резервная копия базы.

Сохранены запуск с частичным переводом, собственные списки, стандартный
выбор папки Windows и статический перевод телефона/UI из 11.23.
CEF-контейнер, native picker и среды запуска не пересобирались.
GitHub и автообновление остаются отложенными.
