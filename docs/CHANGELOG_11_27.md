# 11.27 — автообновления из dev

- Проверка готовой Windows-сборки при запуске, уведомление и установка с перезапуском.
- Рабочая вкладка «Обновления» вместо заглушки. Прогресс загрузки и понятные ошибки.
- Автоматическая Windows-сборка и публикация полного portable ZIP через GitHub Actions.
- Проверка SHA-256, блокировка на время задач, независимый установщик и резервная копия с откатом.
- Модели, игры, настройки, базы и готовые переводы сохраняются; журналы входят в диагностический ZIP.
- Перевод, промпты и профили персонажей не изменены.
