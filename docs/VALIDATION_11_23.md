# Проверки RPTS 11.23

30 октября 2026, Linux. Использованы временные проекты, без загрузки модели и
без запуска реальной Emberbound или Windows/CEF.

72 автоматических теста прошли, включая 9 новых проверок:

- установка частичного перевода из свежей базы поверх устаревшей рабочей сборки;
- обычный запуск без пересборки и изменения установленного патча;
- ошибка установки блокирует запуск;
- пустой перевод не заменяет установленную версию;
- отмена до установки сохраняет игру и базу;
- отклонение некорректного параметра установки;
- блокировка нового запуска до завершения остановки;
- статическое восстановление телефонных сообщений в проекте без отчётов;
- анализ → обычная очередь перевода → сборка → установка телефона и UI.

Последний тест использует исходник с китайскими репликами, кнопками, телефонным
вызовом и двумя разными говорящими. Проверены порядок и авторство сообщений,
включение телефона в обычную очередь и отдельную очередь UI, отсутствие
автоматического захвата, сохранность исходника и данные адаптера в патче.
Провайдер в тесте сценарный: это проверка соединения этапов, а не качества модели.

Браузерная проверка Chromium на настоящем локальном API прошла: два варианта
запуска, частичный перевод, проект без готовых строк, ошибка API в открытом
диалоге, собственные списки с клавиатурой/мышью, сохранение настроек, вкладка
телефона с закрытым по умолчанию захватом, правка строк, версии, диагностика,
задачи и навигация. Проверены размеры 1360×900, 1024×768, 920×680: страницы,
диалог запуска и открытый список помещаются в окно. Ошибок JavaScript и внешних
запросов нет. Ответы нативного выбора папки и команды запуска в браузерном тесте
эмулируются; сборка и установка отдельно проверены backend-тестами.

Console self-check и компиляция Python прошли. Новые JS-файлы прошли проверку
синтаксиса. Проверены CRC обоих ZIP и SHA-256 файлов по release manifest.
Все runtime-файлы, CEF-контейнер, native picker и исходники переводческого ядра,
кроме каталога проектов и desktop API, сохранены побайтно относительно 11.22.

Ограничения: настоящий запуск игры/CEF на Windows и работа живой локальной
модели здесь не проверялись. Статический анализ не обещает извлечь произвольный
текст из любой переработанной игры или изображения; для неразрешённых случаев
остаются отчёт покрытия и ручной захват.
