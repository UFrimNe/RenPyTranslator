# Проверка 11.27

- Основная исходная проверка: 142 теста, успешно на Linux/Python 3.12 и Windows/Python 3.13;
  платформенные проверки пропускаются вне соответствующей ОС.
- Проверены повреждённые/неполные архивы, внешний и внутренний SHA-256, неверный
  канал/адрес, дубли путей, traversal, ADS, symlink, блокировки и отказ загрузки.
- Проверены откат после ошибки замены, восстановление журнала, удаление только
  неизменённых устаревших файлов и сохранение data, моделей и внешних игр.
- Проверены запрет обновления при активном переводе и запрет задач во время обновления.
- На Windows проверены настоящая блокировка файла с откатом и ожидание process
  handle с отменой; в изолированном Python проверен импорт отдельного установщика.
- Node syntax check для app.js и views.js, compileall и launcher self-check успешны.

Исходные тесты не запускают настоящее окно CEF и не имитируют качество
живого перевода. Финальное закрытие CEF, полный цикл обновления с закрытием и повторным открытием CEF
нужно проверять на пользовательской Windows. Алгоритм перевода
и промпты этой задачей не изменялись.
