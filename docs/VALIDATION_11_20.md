# Проверка 11.20

Выполнены 31 автоматическая проверка backend на временных проектах: анализ исходника, создание базы, сохранение версии, установка/откат патча, диагностический ZIP, ручная правка с маркерами и конфликтом версий, блокировки, миграция, отмена, авторизация API и состояние моделей. Автоустановка необязательного декомпилятора отключена только в копии тестового проекта с открытым исходником; сетевые зависимости не загружались. Проверки выполнялись с запретом внешних DNS/соединений и сетевых дочерних команд. Дополнительно проверены новый JS-маршрут, отсутствие сервиса обновления и отклонение его запросов.

Браузерная проверка на реальном локальном API покрывает библиотеку и поиск игр, пять вкладок игры, ручную правку, версии, шаги захвата телефона, девять моделей, сохранение параметров, сохранение черновика при навигации, Ctrl+K, неактивную вкладку обновлений, диагностический ZIP через фоновый исполнитель, задачи, ошибочный путь и выбор папки. Основные страницы и вкладки проверены на отсутствие горизонтального переполнения при 1360×900, 1024×768, 920×680. Ошибок JavaScript и внешних сетевых запросов в сценарии нет.

Код переводчика и все промпты сверяются по SHA-256 с выданным архивом 11.19: изменений нет. Нативный CEF-контейнер, его DLL и среды запуска сохранены без изменений. Это позволяет сохранить уже работавший у пользователя Windows-запуск; новая оболочка не требует другой модели или повторной загрузки весов.

Среда проверки — Linux, Python 3.12 и Chromium headless. Windows CEF, CUDA/Vulkan и новый полный перевод игры в этой среде не запускались. Скриншоты использовались для внутренней проверки макета и в выпуск не включены. Автоматические проверки не являются оценкой художественного качества перевода.

Повторить backend: `runtime/python/python.exe app/tests/test_desktop.py`.

Самопроверка CLI: `runtime/python/python.exe app/tools/rpts_menu.py --self-check`.

Браузерный сценарий: `app/tests/test_frontend.py`, отдельный Python с Playwright/Chromium. Необязательная переменная RPTS_TEST_BROWSER задаёт путь к браузеру. Игровые файлы сценария создаются во временной папке. Снимки сохраняются только при явном задании RPTS_SCREENSHOTS.

Логи текущих проверок — docs/checks_11_20. Результаты 11.19 лежат отдельно и не выдаются за повторно выполненные проверки.
