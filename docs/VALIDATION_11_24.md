# Проверки RPTS 11.24

Повторная проверка 31 октября 2026, Linux. Основа — полная CEF-сборка 11.23.
Исследован RenPyAuditReport от 30 октября с данными RPTS 11.22 / Hy-MT2 7B Q6.
В базе 345 переведённых строк, 3129 pending и 27 runtime_pending.
Это частичный перевод; отсутствие ошибок провайдера не доказывает
правильность смысла и художественного стиля.

## Автоматические проверки

Прошли 89 тестов, включая 17 новых:

- цитата о дружбе за пределами обычного окна соседей;
- отсутствие будущего признания среди ранних опорных цитат;
- отрицание остаётся цитатой, не превращается в статус дружбы;
- явный временной переход разделяет контекст, голос и пакеты;
- «завтра» в диалоге не продвигает время;
- разные label и неупорядоченные каталоги не смешивают социальную память;
- ограничение поиска в старой базе без сведений о ветках;
- буквальное время телефона и разделение его разговоров;
- цитируемая речь в воспоминании;
- ограничение объёма полными цитатами;
- ветки if/else/menu из исходника с сохранением ID сегментов;
- ветки из скомпилированного AST;
- тот же ситуационный контекст в проверочном наборе;
- инструкции времени/отношений для всех девяти моделей каталога,
  сохранение форматов ответа и отсутствие эмоциональных правил для UI;
- сохранение контекста при изоляции, разделении и исправлении строки;
- разные ключи кэша при изменении ситуационного контекста;
- настоящая очередь с одним вызовом сценарного провайдера на строку,
  без нового вызова для анализа отношений.

Остальные тесты охватывают desktop API, исправления перевода и род,
частичную установку, обычный запуск, статический телефон/UI, выбор папки
и диагностику загрузчика. Прошли console self-check и компиляция Python.
Для 43 оценочных сцен сформирован шаблон в dry-run; модель не вызывалась.

## Контекст из отчёта

База открывалась только для чтения. Контекст пересобран для 3397 семантических
строк. 2546 получили ситуационные пометки; у 2350 из них отсутствуют новые
сведения о ветках и действует ограниченный поиск старой базы.
Среди строк с ситуационными пометками дополнительные исходные цитаты
занимают в среднем 41 символ, максимум 152. Эти числа не включают общие
инструкции, имена и служебные поля и не являются количеством токенов.

Сохранены четыре проблемных места с прежним результатом и новым запросом.
К шутке про напоминание возвращена исходная фраза о дружбе детства;
цитата про мороженое получила пометку отдельного голоса и подсказку о 哥.
Новых ответов живой модели эта проверка не производит.
Исходный файл базы не изменён. SHA-256:

`2d5b83ffc7fe17dc2637bf308f35500207c5eaefaf7dd92787fe6d9c3f498a27`

## Сборка и пределы проверки

Проверены CRC обоих ZIP, SHA-256 файлов по release manifest и preflight
загрузчика. Файлы runtime и app/desktop совпадают побайтно с 11.23.
В архив включены выпускные файлы и новые проверки, без временных проектов
и пользовательской базы. Журналы и примеры запросов: docs/checks_11_24/.

Настоящие Hy-MT2, Emberbound и Windows/CEF здесь не запускались.
Художественное качество и время генерации на компьютере пользователя
не измерены. Проверены извлечение контекста, передача запросов и контракты,
а не гарантированно удачная адаптация. Полный граф прохождения и всех
временных линий не строится; границы определяются консервативно по веткам
и явным повествовательным признакам.
