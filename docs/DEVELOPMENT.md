# Разработка

Репозиторий хранит исходники RPTS. Полная пользовательская сборка отдельно
содержит Python/.NET/CEF и не равна архиву GitHub **Code → Download ZIP**.
Исходники импортированы из версии 11.26 без изменения алгоритмов перевода.

## Папки

| Путь | Содержимое |
| --- | --- |
| `app/src/rpts` | Извлечение текста, модели, перевод, проверки, база и патчи |
| `app/tools` | Консольное меню, сервер GUI и исполнитель фоновых задач |
| `app/web` | HTML/CSS/JavaScript интерфейса CEF |
| `app/desktop/src` | Исходники CEF-контейнера C# |
| `app/desktop/picker` | Отдельный стандартный диалог папки Windows |
| `app/templates` | Примеры настроек и оценочные сцены |
| `app/tests` | Регрессионные и дополнительные браузерные тесты |
| `docs` | Инструкции пользователя, сборки и история изменений |

## Python и тесты

Для исходников и автообновления требуется Python 3.11 или новее. Основные тесты используют
стандартную библиотеку и временные проекты. Они не скачивают модель
и не запускают настоящую игру или CEF.

Из корня репозитория:

```sh
python app/tools/check_source.py
python -m compileall -q app/src app/tools app/tests
python app/tools/rpts_menu.py --self-check
```

В базе 11.26 основная проверка содержит 123 теста. Дополнительный
`app/tests/test_frontend.py` требует Playwright и установленного Chromium;
он не входит в `check_source.py`.

Консольное меню из исходников:

```sh
python app/tools/rpts_menu.py
```

Portable BAT/VBS-файлы ожидают комплектные среды в `runtime` и собранный
контейнер в `app/desktop/bin`. После обычного клонирования этих файлов нет.

## Окно CEF

На Windows установи .NET 8 SDK и выполни из PowerShell:

```powershell
./app/desktop/build.ps1
```

Скрипт восстанавливает зафиксированную зависимость CefSharp из NuGet,
собирает контейнер и отдельный процесс выбора папки. Детали запуска
и обмена с Python описаны в [BUILD_CEF.md](BUILD_CEF.md).
Версия native-контейнера имеет свою историю; не меняй её только ради
совпадения с номером Python-приложения.

Для полноценной переносимой сборки дополнительно нужны комплектные Python,
.NET runtime, CEF-зависимости и установщик VC Runtime. Они не хранятся в Git.
Полные Windows-сборки выпускает `.github/workflows/release.yml`.
Устройство канала, формата архива и восстановления описано в [UPDATES.md](UPDATES.md).

## Ветки и поставка

Рабочая и публичная ветка — `main`. Дополнительная ветка разработки временно убрана.

Полные ZIP для пользователя собираются отдельно. Не коммить `runtime`,
`data`, `projects`, игры, GGUF, базы переводов, журналы и результаты диагностики.
Исключения перечислены в корневом `.gitignore`.

Использованные иконки и их атрибуция сохранены в
`app/FLATICON-LICENSE.txt` и `app/ICON_SOURCES.json`. Этот импорт не назначает
проекту новую лицензию и не меняет лицензии сторонних компонентов.

Полная сборка: [BUILD_WINDOWS.md](BUILD_WINDOWS.md). Публичный main выпускает
версионный релиз. Сейчас используется только main.
