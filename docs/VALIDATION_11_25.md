# Проверки RPTS 11.25

31 октября 2026. Linux, основа — полная сборка 11.24.

Проверка отчёта Bruder выполнена только для чтения. Исходная база не менялась.
Из 11 неизвестных профилей по источнику устанавливается мужской род у
j, q, x, x_1, z и l4. l1/l2/l3/l5/l6 остаются unknown. Отмечены 15 готовых
автоматических строк с конфликтами согласования; проверены три новых запроса.
Ни одна пользовательская строка при этой проверке не переписывалась.

SHA-256 исходной базы:

`0baa5fcaab11dff9b5d3f940e2c42cfe52866fcc09e7d654a9a014e5018cf3a4`

Новые тесты охватывают род адресата вместо говорящего, именованное
представление, локальную фамильную ссылку, отрицание, цитаты, неоднозначного
собеседника, границы веток, фиксированные имена и согласие известных родов,
отказ при смешанном/неизвестном роде, отсутствие выдуманного ID рассказчика,
проверку названного субъекта, «сначала», ручную блокировку, сканирование
без записи в базу, SQLite backup с закрытием соединений, точный выбор строк,
обычный запуск после адресного режима, реальную очередь со сценарным
провайдером, сохранность старого текста при ошибке и отмену до модели/backup.

Прошли 105 тестов, включая 16 новых. Дополнительно выполнены прежние тесты сцен, desktop API, ремонта строк,
телефона/UI, частичной установки, выбора папки и загрузчика. Итоговое число
и результат записаны в docs/checks_11_25/unit.log. Console self-check,
компиляция Python и синтаксис изменённых JavaScript проверены.

CRC обоих ZIP, хеши выпускных файлов и preflight загрузчика проверены при
упаковке. runtime и app/desktop сохранены побайтно относительно 11.24.
Изменение интерфейса ограничено дополнительным действием в инструментах;
нативное окно и выбор папки не пересобирались.

Ограничения: настоящие Hy-MT2, Windows/CEF и игра не запускались.
Качество новых ответов модели не измерено. Проверки не являются полным
морфологическим анализатором и не гарантируют нахождение всех ошибок.
Согласие рода локальных кандидатов — ограниченная контекстная подсказка,
а не установленная личность рассказчика или полная карта точек зрения.
В смешанных или неоднозначных случаях система оставляет род неизвестным.

Журналы, исходные свидетельства и запросы: docs/checks_11_25/.
